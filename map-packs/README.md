# SurvivalAI map packs

Offline region packages for SurvivalAI: a vector map, places, and Valhalla routing tiles for one region.
`index.json` lists them with size and SHA-256. The zips are release assets (`maps-2026-10-22`), not files in git.

Data: OpenStreetMap (ODbL, (c) OpenStreetMap contributors), Geofabrik extracts, Protomaps basemap tiles,
Valhalla routing tiles (Valhalla is MIT). Build with `tools/maps/build_region.py` in the SurvivalAI repo.
